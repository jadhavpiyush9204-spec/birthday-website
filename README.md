# Birthday Surprise Website

1. Install Node.js 18+ from nodejs.org
2. In this folder run:  npm install
3. Then run:            npm run dev   (open the link it prints)
4. Edit CFG and MEM at the top of src/App.jsx (her name, your name, birthday date, photos)
5. To share: npm run build, then drag the dist folder onto https://app.netlify.com/drop
